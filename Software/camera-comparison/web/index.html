Preview holds the camera lock. Stop preview before recording. Closing this tab or the SSH tunnel does NOT stop capture. Stop the preview in the Pi terminal (Ctrl+C), or stop its service.

Direct V4L2 raw acquisition. No automatic saving. Native capture continues at the configured sensor rates; the browser skips intermediate frames and fetches only the latest.

No Pi ISP, AE/AGC, gamma curve, denoising, sharpening, or per-frame normalization. GREY maps directly to grayscale; Y10P maps native value >> 2. Smooth mode compresses this display with JPEG. Raw mode preserves native data.

Exposure changes are preview-only; stopping preview restores its startup settings. Gain remains fixed at 1x. Exposure estimates are not optical measurements. Sensor-internal corrections remain those programmed by the recording driver.

JPEG compression can affect fine texture; use Raw pixels to confirm fine detail. A retained image with an overlay is NOT live. Display age is a lower bound, not end-to-end latency.
